# Coffee Sales Trend & Spend Analysis (Power BI)

This project analyzes coffee sales data using Microsoft Power BI to identify spending patterns, peak sales hours, and customer purchasing behavior.

## Tools Used
- Microsoft Power BI
- CSV dataset
- Power Query
- DAX measures

## Key Insights
- Peak coffee purchase time occurs around 10 AM
- Weekday sales contribute more revenue than weekends
- Tuesday shows the highest spending among weekdays
- Morning purchases dominate coffee sales

- Coffee_Data.pbix – Power BI dashboard
